# 学而篇第一

## 开篇三句

子曰：「学而时习之，不亦说乎？有朋自远方来，不亦乐乎？人不知而不愠，不亦君子乎？」

这段话把学习、交友、修养三件事放在一起，是《论语》全书的总入口。

## 孝悌为本

有子曰：「其为人也孝弟，而好犯上者，鲜矣；不好犯上，而好作乱者，未之有也。君子务本，本立而道生。孝弟也者，其为仁之本与！」

> 本立而道生——先站稳根本，方法自然长出来。

## 吾日三省

曾子曰：「吾日三省吾身：为人谋而不忠乎？与朋友交而不信乎？传不习乎？」

三省的重点不在次数，而在「忠、信、习」三个可检验的动作。

## 小结

| 章句 | 关键词 | 今日可做 |
| --- | --- | --- |
| 学而时习 | 复习 | 把学过的内容讲一遍 |
| 三省吾身 | 反省 | 睡前写三行复盘 |
| 本立道生 | 根本 | 先做最重要的一件事 |

学习的闭环可以写成伪代码：

```text
输入 -> 练习 -> 反馈 -> 修正 -> 再练习
```

缺任何一环，都只是「看过」。
